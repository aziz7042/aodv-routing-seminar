# Reactive Routing with AODV

An authored seminar paper on **Ad hoc On-Demand Distance Vector (AODV)** routing in wireless multi-hop ad hoc networks.

## Topics covered

- Reactive route discovery with RREQ and RREP messages
- Expanding Ring Search and routing-table maintenance
- Route errors and link-break handling with RERR messages
- Destination sequence numbers and loop freedom
- Comparison with proactive protocols and DSR
- Packet delivery, delay, throughput and normalized routing load
- Practical applications, protocol extensions and limitations

The paper is available in [`paper/Reactive-Routing-Using-AODV.pdf`](paper/Reactive-Routing-Using-AODV.pdf).

## Figure provenance

The PDF contains four schematic diagrams prepared as explanatory figures for this seminar paper: infrastructure comparison, AODV route discovery, Expanding Ring Search and route maintenance.
